# SOP: Multi-Source Ingestion & Knowledge Synthesis

## 1. Supported Sources & Limits
- Maximum **5 heterogeneous sources** per `/api/weave` request (`topic`, `youtube`, `pdf`, `text`).
- Uploaded files accept `.pdf`, `.txt`, and `.md` only, capped at **20 MB** (`20 * 1024 * 1024` bytes) per file.
- YouTube inputs must pass `extractYouTubeId()` matching `^[a-zA-Z0-9_-]{11}$` (strict allowlist; never fetches arbitrary URLs).

## 2. Segment Normalization & Caching Hash
- Every ingested source produces a `SourceDocument` with SHA-256 `rawTextHash` and indexed `SourceSegment[]`:
  - **PDF:** Parsed via a coordinate-aware `pdfjs-dist/legacy/build/pdf.mjs` layout pass (`src/lib/ingestion/pdf-layout.ts`) using viewport coordinates (`convertToViewportPoint`), running header/footer/page-number stripping (top/bottom 6% margin bands), gutter-safe visual-line grouping, page-level single vs. two-column vertical-zone reading order (preserving full-width titles/abstracts/figures), median-font-size + bold + academic section heading emission (`## Heading`), hyphenation repair, and Markdown table extraction. Evaluates meaningful alphanumeric character counts (`< 50` chars on multi-page PDFs, `< 10` chars on 1-page PDFs) with zero synthetic page-joiner markers (`-- 1 of N --`), throwing explicit errors for scanned/empty, password-protected, or invalid/corrupted PDFs without making unrequested paid vision API calls.
  - **Text / Markdown & Chunking:** Split by Markdown headings (`#`–`####`) and paragraphs with `heading` preserved (`chunkTextIntoSegments()` targets `~800` chars per segment, max `1,500` chars, capped at `200` segments per `SourceDocument`, propagating active `heading` across PDF pages and preserving Markdown table blocks intact without collapsing row newlines).
  - **YouTube:** Fetches `https://www.youtube.com/watch?v=${videoId}`, extracts video title, description chapter timestamps (`MM:SS` / `HH:MM:SS`), and timed caption tracks (`captionTracks` XML) into `startSec`/`endSec` segments when available.
  - **Topic Prompt:** Generates a canonical topic segment (`index: 0`).

## 3. Grounded Multi-Source Synthesis & Offline Fallback
- `weaveSourcesToWorkspace()` uses stratified whole-document sampling (`sampleStratifiedSegments()` in `src/lib/ingestion/segment-ranker.ts`, selecting up to `24` opening/middle-heading/table/closing segments × `750` chars while excluding/de-prioritizing `References`) and invokes `runAICompletion()` with `jsonMode: true` and `maxTokens: 8192` to synthesize 1–5 `SourceDocument`s into a single tree (`rootNode` + 2–3 levels), attaching `SourceAnchor` references (`segmentId`, `pageNumber` or `timestampSec`, verbatim `excerpt`, and `agreement`: `consensus` | `unique` | `contradiction` when `sources.length >= 2`), initial `CrossLink`s, `BlindSpotInsight`s, and `WalkthroughStep`s. Output passes through nullish-safe Zod normalization (`RawWeaveOutputSchema`) with field clamping to `MindMapWorkspaceSchema` bounds and 1 automatic compact-JSON retry (`weave.json_retry`) if initial JSON parsing or schema validation fails.
- **Zero-Key Offline Fallback:** When `isLiveAIConfigured()` is `false`, `buildDeterministicWorkspaceFromSources(sources)` uses `sampleStratifiedSegments()` to build a structured, source-anchored `MindMapWorkspace` directly from extracted segments/headings/tables/chapters without blocking the user, and `createFlagshipDemoWorkspace()` provides the rich sample workspace (*"Transformer Architecture & Scaling Laws"*).
